# More Mobs! Addon
Feel free to use this addon in your videos or streams! Please just link back to this page.

**🐻 Another Bear!!!**

Ever felt like Minecraft's forests were missing something? This lightweight addon introduces Brown Bears to your Bedrock worlds!

**✨ Features**

Where to Find Them: Brown bears naturally spawn in Taiga, Snowy Taiga, and Forest biomes.
Behavior: They are neutral but will defend themselves if attacked, or if you go near their cubs!
Unique Drops: Instead of the usual catch, defeating a brown bear drops Brown Dye and Feathers!

**🛠️ Installation**

Download the .zip file, and rename to 'MoreMobsMinecraftAddon-main.mcaddon', close Minecraft via Task Manager, and open the .mcaddon file to automatically install it.
Apply the pack to your world's behavior and resource pack settings.
No experimental toggles required!
